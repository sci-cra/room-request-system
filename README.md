# 🏛️ ระบบขอใช้ห้องนอกเวลาทำการ (After-Hours Room Booking System)
### คณะวิทยาศาสตร์ • อาคารวิจัยและเรียนรู้เฉลิมพระเกียรติ 60 พรรษา เจ้าฟ้าจุฬาภรณ์

ระบบเว็บแอปพลิเคชันสำหรับยื่นขอใช้ห้องเรียน ห้องปฏิบัติการ และห้องประชุม นอกเวลาทำการ เพื่อดำเนินการขออนุมัติเปิดระบบไฟฟ้าและระบบปรับอากาศ บันทึกข้อมูลเข้า **Google Sheets** อัตโนมัติ พร้อมระบบจัดการสถานะสำหรับเจ้าหน้าที่ และระบบออกร่างหนังสือบันทึกข้อความราชการ

## 🟢 ส่วนที่ 1: การเชื่อมต่อกับ Google Sheets (ใช้แทน Database)

> **ข้อดี:** ไม่ต้องสร้างหัวตารางเอง แม้ Sheet จะว่างเปล่า โค้ดจะสร้างหัวตารางทั้ง 17 คอลัมน์และจัดสีให้อัตโนมัติทันที พร้อมส่งไฟล์แนบไปเก็บใน Google Drive!

1. เปิด [Google Sheets](https://sheets.new) เปล่าขึ้นมา 1 ไฟล์
2. ไปที่เมนู **ส่วนขยาย (Extensions)** ➡️ **Apps Script**
3. ลบโค้ดเดิมในหน้านั้นออก แล้วนำโค้ดในไฟล์ [`google-apps-script.js`](./google-apps-script.js) ไปวางทั้งหมด
4. กดรูป **บันทึก (แผ่นดิสก์)**
5. กดปุ่มสีน้ำเงินมุมขวาบน **การทำให้ใช้งานได้ (Deploy)** ➡️ เลือก **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
6. กดรูปฟันเฟือง ⚙️ ด้านซ้าย เลือก **เว็บแอป (Web app)**
7. กำหนดค่า:
   - **คำอธิบาย:** ระบบขอใช้ห้อง
   - **ดำเนินการในฐานะ (Execute as):** `ตัวฉัน (Me)`
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)` *(สำคัญมาก)*
8. กด **ทำให้ใช้งานได้ (Deploy)** และกดยอมรับสิทธิ์ (Authorize Access)
9. ก๊อปปี้ **"URL ของเว็บแอป"** (ที่ลงท้ายด้วย `/exec`)
10. เปิดหน้าเว็บระบบ ➡️ ไปที่แท็บ **"สำหรับเจ้าหน้าที่"** (รหัส: `1234`) ➡️ กดปุ่ม **"ตั้งค่า Google Sheet"** ➡️ วาง URL ลงไปแล้วกด **บันทึกการเชื่อมต่อ**

## 🚀 ส่วนที่ 2: วิธีนำโปรเจกต์ขึ้น Git และ GitHub (พร้อมเปิดเว็บฟรี)

### วิธีที่ 1: อัปโหลดผ่านหน้าเว็บ GitHub (ง่ายที่สุด ไม่ต้องลงโปรแกรม Git)

1. เข้าเว็บไซต์ [GitHub.com](https://github.com/) แล้วล็อกอินบัญชีของคุณ
2. กดปุ่มเครื่องหมายบวก **`+`** ด้านบนขวา ➡️ เลือก **New repository**
3. ตั้งชื่อ Repository เช่น `room-request-system` 
4. เลือกเป็น **Public** แล้วกดปุ่มเขียว **Create repository**
5. ในหน้าใหม่ที่ปรากฏขึ้นมา มองหาข้อความ **"uploading an existing file"** แล้วคลิกเข้าไป
6. เปิดโฟลเดอร์ในเครื่องของคุณ:
   `C:\Users\noona\.gemini\antigravity\scratch\room-request-system`
7. **ลากไฟล์ทั้งหมดไปวางในหน้าเว็บ GitHub:**
   - `index.html`
   - `app.js`
   - `google-apps-script.js`
   - `.gitignore`
   - `README.md`
8. เลื่อนลงมาด้านล่าง กดปุ่มเขียว **Commit changes** ➡️ ขึ้น GitHub เรียบร้อยแล้ว!

### ⭐ วิธีเปิดเว็บไซต์ออนไลน์ให้ทุกคนเข้าใช้งานฟรี (GitHub Pages)

หลังจากนำขึ้น GitHub แล้ว สามารถเปิดเป็นเว็บไซต์ให้ทุกคนกดเข้าใช้งานได้ทันที:

1. ในหน้า GitHub Repository ของคุณ กดไปที่แท็บ **Settings** (เมนูด้านบนขวา)
2. เมนูด้านซ้าย เลือกหัวข้อ **Pages**
3. ที่หัวข้อ **Build and deployment > Branch**:
   - เปลี่ยนจาก `None` เป็น **`main`**
   - โฟลเดอร์เลือกเป็น **`/(root)`**
   - กดปุ่ม **Save**
4. รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์สำหรับใช้งานจริง เช่น:
   `https://<ชื่อผู้ใช้ของคุณ>.github.io/room-request-system/`
5. นำลิงก์นี้ไปส่งให้อาจารย์, เจ้าหน้าที่ หรือทำเป็น QR Code แปะหน้าห้องแล็บได้ทันทีครับ!
